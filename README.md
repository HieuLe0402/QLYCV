# 📝 Quản Lý Công Việc (Todo List App)

Ứng dụng quản lý công việc hiện đại, trực quan và tiện lợi, được xây dựng bằng HTML5, CSS3 và Vanilla JavaScript.

## 🚀 Tính năng nổi bật

- 📌 **Giao diện hiện đại**: Thiết kế căn giữa trang nhã, màu sắc hài hòa với tone màu chủ đạo `#26A69A`.
- ➕ **Thêm công việc mới**: Nhập tên công việc, nhấn phím **Enter** hoặc nút **"Thêm"** (`#66BB6A`). Có validate không cho phép nhập rỗng.
- 📋 **Danh sách trực quan**: Hiển thị trạng thái rỗng khi chưa có công việc.
- ✅ **Đánh dấu hoàn thành**: Tích chọn checkbox để hoàn thành, tên công việc được gạch ngang mượt mà.
- ✏️ **Chỉnh sửa công việc**: Nút **"Sửa"** chuyên dụng, hỗ trợ lưu nhanh bằng phím **Enter** hoặc hủy bằng phím **Escape**.
- 🗑️ **Xóa công việc**: Hộp thoại (modal) xác nhận xóa an toàn trước khi thực hiện.
- 📊 **Thống kê Footer**: Tự động đếm tiến độ `X/Y công việc hoàn thành`.
- 🏆 **Badge hoàn thành tất cả**: Xuất hiện huy hiệu chúc mừng với animation sinh động khi hoàn tất toàn bộ công việc.
- 💾 **Lưu trữ dữ liệu**: Tự động đồng bộ với `localStorage`, không lo mất dữ liệu khi tải lại trang.

## 🛠️ Công nghệ sử dụng

- **HTML5**: Cấu trúc ngữ nghĩa (Semantic HTML), hỗ trợ trợ năng (Accessibility - ARIA).
- **CSS3**: Vanilla CSS, Flexbox, Keyframe Animations, CSS Variables.
- **JavaScript**: Vanilla ES6+, Module pattern, Event Delegation, LocalStorage API.
- **Icons**: Font Awesome 6.

1. Clone repository về máy:
